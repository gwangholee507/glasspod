# T18 Pod 목록 화면

- 우선순위: P0 · 단계 9 · 선행 작업: T14, T17 · 결정: D9
- 브랜치: `feat/t18-pod-list`
- 작성: 2026-11-17

## 목표

웹 화면을 확정안(design.md 5.3, Figma '확정-1 목록')의 분할 화면으로 바꾸고, Pod 목록을 실시간으로 보여 줍니다. T19(상세)는 오른쪽 자리만 채우면 되게 합니다.

- 틀: 왼쪽 메뉴(namespace 고르기, 메뉴, 실시간 연결 상태) · 가운데 Pod 목록 · 오른쪽(고르기 전에는 한눈에 보기, 고르면 상세 자리)
- 목록: '지금 볼 것'(위험·주의)을 맨 위에, 그 아래 판단별 묶음. 탭으로 '문제'만 보기와 'Deployment별' 묶기. 이름으로 찾기
- 항목: 상태 배지, 5xx/분(0보다 클 때), 판단이 이어진 시간, Pod 이름, 판단 문장, 지표 3개(이벤트 루프 p99, 힙 사용, 요청 p99)
- 오른쪽, 고르기 전: Deployment별 요약(쿠버네티스 Ready 수와 판단별 수)과 최근 30분 판단 변화 타임라인
- 글꼴 3종을 npm 패키지로 번들에 넣음(T17에서 넘김, 2026-11-14 결정)

## 결정 사항

1~3은 2026-11-17에 사용자가 정했습니다(착수 전에 보고한 질문 3개). 4~24는 이 작업의 기본값입니다. 결정 18의 '스트림 기록 비우기'와 결정 25는 구현하며 확인한 것(아래 '구현하며 확인한 것')으로 더했습니다.

## 판단 문장

`now`는 서버 시계(결정 12), `N`은 결정 11의 시간 형식입니다.

| 판단 | 목록(명사형) | 타임라인('~습니다') |
| --- | --- | --- |
| `terminated` | `terminating` 'Pod를 끝내는 중', `deleted` '쿠버네티스에서 지워짐', `Succeeded` 'Pod가 끝남 (Succeeded)' | 'Pod를 끝내는 중입니다.', '쿠버네티스에서 지워졌습니다.', 'Pod가 끝났습니다 (Succeeded).' |
| `pod-failing` | `Failed` 'Pod 실패 (Failed)', 그 밖 '컨테이너를 띄우지 못함 (<reason>)' | 'Pod가 실패했습니다 (Failed).', '쿠버네티스가 컨테이너를 띄우지 못합니다 (<reason>).' |
| `stalled` | 'metrics N째 없음 · 이벤트 루프 막힘 의심'(N은 `sdk.lastMetricsAt`, 없으면 `connectedAt`부터) | 'metrics가 3주기 동안 오지 않았습니다.' |
| `disconnected` | 'SDK 연결이 N 전에 끊김'(`sdk.disconnectedAt`) | 'SDK 연결이 끊겼습니다.' |
| `restarted` | `restart.reason`이 있으면 '<reason> (<exitCode>)로 재시작', 없으면 '새 instance로 다시 붙음' | 'Pod가 재시작했습니다. 쿠버네티스 종료 이유 <reason>.', 이유가 없으면 '새 instance로 다시 붙었습니다.' |
| `not-ready` | 'SDK는 정상 · 쿠버네티스 Ready 아님' | '쿠버네티스가 Pod를 Ready로 보지 않습니다.' |
| `starting` | '시작 중 (<reason>)' | 'Pod를 시작하는 중입니다 (<reason>).' |
| `no-sdk` | '쿠버네티스 정보만 봄' | 'SDK가 붙지 않은 Pod입니다.' |
| `ok` | '이상 신호 없음' | 이전 판단이 없으면 '이상 신호가 없습니다.', 있으면 '다시 정상입니다.' |
