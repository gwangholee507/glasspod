지침서와 다르게 하거나 새로 정한 것:

- 내장 WebSocket을 고르면서 SDK 원칙 '앱의 종료 동작을 바꾸지 않음'에 예외가 생김. 연결된 동안에는 이벤트 루프가 비지 않으므로, 이벤트 루프가 비기를 기다려 끝나는 앱은 `glasspod.stop()`을 불러야 함. design.md 5.1과 `CLAUDE.md`에 적음
- 확인 중에 경고 문구를 하나 고침: 서버 주소의 scheme이 틀렸을 때 `(got http://)` 대신 `(got "http:")`
- T03에서 미뤄 둔 `RejectReason` 이동은 하지 않음. SDK가 reason에 따라 다르게 동작하지 않기 때문
